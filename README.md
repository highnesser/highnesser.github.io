## Editing

The whole site is a single self-contained file: `index.html` (CSS inline, images embedded as base64 data URIs). Edit it, commit, and push — GitHub Pages redeploys automatically in about a minute.

```bash
git add index.html
git commit -m "Update portfolio"
git push
```
